# Maintenance status

**Frozen at v0.2.1.**

No new features are planned. Security-class bugs only, best-effort. PRs
may sit. If you need this to evolve, fork it — the MIT license is
generous on purpose.

## What "frozen" means here

- The published artifact (`cargo install biblion`) keeps working against
  the schemas it was built for.
- Bug reports stay open; security-class issues will be looked at as time
  allows.
- Non-security PRs may be reviewed eventually, may not.
- No release cadence. No roadmap. No public coordination on direction.

## What it does not mean

- The repository is **not** archived. Issues and PRs remain open; the
  code is still readable, forkable, and citable.
- v0.2.0 and v0.2.1 stay published on crates.io. They are not yanked.
  If you depend on them, they keep working.

## If you want this to evolve

Fork it. The MIT license is the contract — there is no extra permission
needed, no contributor license agreement, no upstream dependency on the
original author. A fork is a first-class continuation.

Last actively-developed release: **v0.2.1**.
